# KERAFED Financial Statement Analysis

## 📌 Project Overview

This project focuses on the financial statement analysis of KERAFED (Kerala Karshaka Sahakarana Federation), Thiruvananthapuram. The study examines the organization's financial performance using financial statement analysis techniques to understand its financial position, operational efficiency, and overall performance.

## 🎯 Objectives

- To analyze the financial position of KERAFED.
- To evaluate liquidity and short-term financial stability.
- To examine profitability and solvency.
- To analyze working capital management.
- To identify financial trends and provide suitable suggestions.

## 🔍 Scope of the Study

The study focuses on understanding KERAFED's financial performance through the examination of financial statements and relevant financial indicators. It aims to identify strengths, weaknesses, and areas that may require improvement.

## 🛠️ Methodology

The project uses financial statement analysis techniques to evaluate the financial performance of KERAFED.

**Analysis techniques:**
- Ratio Analysis
- Trend Analysis
- Liquidity Analysis
- Profitability Analysis
- Solvency Analysis
- Working Capital Analysis

## 📊 Key Areas of Analysis

- **Liquidity:** Evaluates the organization's ability to meet short-term obligations.
- **Profitability:** Examines financial results and earning performance.
- **Solvency:** Assesses the organization's long-term financial stability.
- **Working Capital:** Reviews the management of current assets and current liabilities.
- **Financial Trends:** Examines changes in financial performance over the study period.
